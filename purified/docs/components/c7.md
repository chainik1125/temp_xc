## Hypothesis

On the Ward et al. 2025 backtracking case study (Stage B), TXC-pro
delivers the largest peak Δgc (gain in keyword rate when steering toward
the inducement direction) — roughly 3× the next-best architecture.
This is the "TXC pushes the Pareto frontier on a behavioural inducement
metric" claim.

## Setup

- **Subject model**: `google/gemma-2-2b` (BASE) — backtracking task is
  base-model behaviour.
- **Hookpoints**: layer 10 residual / attention / `ln1` (per Aniket).
- **Architectures**: TopK-SAE, Stacked-SAE, TFA, T-SAE (paper config k=20),
  TXC-base, TXC-pro, MLC. Seven total — locked set + MLC for cross-arch
  context (since C3's `mlc` baseline carries through).
- **Two metric axes**:
  - **Inducement (Δgc)**: keyword rate increase under steering, grade
    by Sonnet-judge with κ ≥ 0.6 vs blind hand-score.
  - **Detection (PR-AUC)**: linear probe on activations.
- **Magnitude grid**: densified per Aniket's 2026-05-03 push.
- **Seeds**: {1, 2, 42} where compute permits.
- **Hardware**: 1× A40, ~3 hr per full sweep.
