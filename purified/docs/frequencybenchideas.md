# FrequencyBench

*Three synthetic benchmarks for temporal-architecture frequency response.*

**Status:** rough proposal — pedagogical draft, not yet a paper outline.

## Abstract

Temporal architectures can use context in qualitatively different ways. Some
behave mostly as *temporal smoothers*: they average repeated noisy evidence
for a stable latent. Others behave as genuine *temporal filters*: they recover
order-sensitive, high-frequency, or phase-localized structure.

This note proposes **FrequencyBench**, a three-part synthetic benchmark
suite that measures these mechanisms directly. The suite contains:

1. a **DC-only** smoothing task,
2. an **AC-only** high-frequency signed-motion task, and
3. a **mixed ten-frequency** cyclic-HMM task.

For each task we write the HMM, the actual synthetic activations used to
train dictionary learners, a short proof that the one-token distribution
gives a local ceiling, a proof that the process does not factorize over
tokens, and preregistered predictions for SAEs, TXCs, T-SAEs, TFAs, and
frequency-split temporal architectures.

## 1. Why a frequency benchmark?

A temporal architecture should not be characterized only by whether it beats
a per-token SAE. There are many ways to use context. A model may win because
it averages several noisy samples of the same latent, or because it detects
a truly order-sensitive pattern. These are different inductive biases.

The useful mental model is to treat an encoder atom as a **temporal filter**.
If a windowed encoder atom has weights

$$
e_{j,0}, e_{j,1}, \ldots, e_{j,W-1}
$$

then its preactivation on a window $X = (x_0, \ldots, x_{W-1})$ is

$$
p_j(X) = \sum_{\tau=0}^{W-1} \langle e_{j,\tau}, x_\tau \rangle.
$$

The coarsest decomposition is

$$
e_{j,\tau} = \bar e_j + \widetilde e_{j,\tau}, \qquad
\sum_{\tau=0}^{W-1} \widetilde e_{j,\tau} = 0,
$$

where

$$
\bar e_j = \frac{1}{W} \sum_{\tau=0}^{W-1} e_{j,\tau}.
$$

The term involving $\bar e_j$ is the **DC** or *smoothing* component.
The zero-mean term is the **AC** or *order-sensitive* component.
DC vs AC is only the first split, however. In principle the atom has a full
temporal spectrum. Choose an orthonormal temporal basis
$\psi_\omega(\tau)$ — for example a real Fourier or DCT basis — and write

$$
e_{j,\tau} = \sum_{\omega=0}^{W-1} \widehat e_j(\omega)\, \psi_\omega(\tau).
$$

Then $\omega = 0$ is DC, while $\omega > 0$ are distinct nonzero temporal
frequencies. We define the **frequency profile** of an atom by

$$
\mathrm{FreqFrac}_j(\omega) =
\frac{\|\widehat e_j(\omega)\|^2}{\sum_{\omega'} \|\widehat e_j(\omega')\|^2}.
$$

The old DC fraction is simply $\mathrm{FreqFrac}_j(0)$.

**Goal.** FrequencyBench asks: *which temporal frequencies does an
architecture recover?* The proposed benchmarks are:

1. A **DC-only** task, where context helps only by smoothing repeated noisy
   observations.
2. An **AC-only** task, where the signal is a high-frequency ordered
   transition and mean-pooling provably fails.
3. A **mixed ten-frequency** task, where we plot a frequency-response curve
   for each architecture.

## 2. Common synthetic-data interface

We keep the same interface as the usual synthetic dictionary-learning setup.
A sequence of binary firing masks

$$
A = (a_{t,i}) \in \{0,1\}^{T \times N}
$$

is generated by a temporal process. A set of ground-truth feature directions

$$
\mathcal F = \{f_1, \ldots, f_N\} \subset \mathbb R^d
$$

is fixed. Magnitudes $m_{t,i}$ are sampled independently of the hidden
temporal label unless otherwise stated. The actual activation given to the
encoder is

$$
x_t = \sum_{i=1}^{N} a_{t,i}\, m_{t,i}\, f_i + \sigma\, \epsilon_t.
$$

The temporal process controls the masks $a_{t,i}$; the architecture never
sees the hidden label directly.

For the symbolic tasks below, an emitted symbol $Q_t \in \mathcal X$ is
converted into a one-hot mask by assigning one feature direction $u_a$ to
each alphabet symbol $a \in \mathcal X$:

$$
a_{t,i} = \mathbf 1\{i = Q_t\}, \qquad
x_t = u_{Q_t} + \sigma\, \epsilon_t.
$$

Multi-lane variants use several simultaneous symbols and hence multi-hot
masks.

## 3. Metric: a global temporal probe score

Every task has a hidden temporal mode $Y$ or $C$ that is *not* merely a local
emission. For an architecture, let $z_t$ or $z_{t:t+W-1}$ denote the
representation that will be probed. For a windowed architecture this may be
the window code; for a per-token architecture it may be a stacked window of
per-token codes. We train the **same held-out probe class** across
architectures to predict the hidden temporal label.

Let $A_\mathrm{model}$ be held-out probe accuracy, $A_\mathrm{loc}^\star$ the
Bayes-optimal accuracy from a single token, and $A_\mathrm{oracle}$ the
accuracy of a symbolic temporal oracle that sees the clean emitted window.
Define the **normalized temporal probe score**

$$
S_\mathrm{temp} =
\frac{A_\mathrm{model} - A_\mathrm{loc}^\star}{A_\mathrm{oracle} - A_\mathrm{loc}^\star}.
$$

- $S_\mathrm{temp} = 0$: model is at the local ceiling (no temporal lift).
- $S_\mathrm{temp} = 1$: model matches the temporal oracle.
- If the numerator is negative, we report both the raw value and a clipped
  $\max(0, S_\mathrm{temp})$.

For the ten-frequency task we additionally report a **frequency-response
curve**. If $\Omega$ is the set of ten hidden frequencies, define

$$
A(\omega) = \mathbb P(\widehat Y = Y \mid Y = \omega),
\qquad
S(\omega) = \frac{A(\omega) - 1/|\Omega|}{1 - 1/|\Omega|}.
$$

The plot $\omega \mapsto S(\omega)$ is the architecture's empirical temporal
frequency response.

## 4. Benchmark 1: DC-only smoothing

### 4.1 Process definition

The hidden label is a stable class

$$
C \sim \mathrm{Unif}([K]).
$$

At each token we observe a noisy local copy through a $K$-ary symmetric
channel. With probability $p$ the emitted symbol is correct; otherwise it
is a uniformly random incorrect symbol:

$$
\mathbb P(Q_t = a \mid C = c) =
\begin{cases}
p, & a = c, \\
\tfrac{1-p}{K-1}, & a \neq c.
\end{cases}
$$

Given $Q_t$, the activation is $x_t = u_{Q_t} + \sigma\, \epsilon_t$.

Conditioned on $C$, the emissions are independent across $t$. Unconditionally,
all tokens are coupled through the shared class $C$.

### 4.2 HMM

The HMM state is the class $C$, which is constant across the block
($C_{t+1} = C_t$). This is "HMM" in a degenerate sense: a single hidden
parameter shared across all tokens. A standard state-emitting presentation
has

$$
\mathbb P(C_{t+1} = c', Q_t = a \mid C_t = c)
= \mathbf 1\{c' = c\} \cdot \mathbb P(Q_t = a \mid C = c).
$$

Equivalently, in edge-emitting notation, for each emitted symbol $a \in [K]$,

$$
T^{(a)}_{c, c'} = \mathbf 1\{c' = c\}
\begin{cases}
p, & a = c, \\
\tfrac{1-p}{K-1}, & a \neq c.
\end{cases}
$$

### 4.3 Local ceiling

A single token is informative but noisy. The Bayes-optimal one-token
classifier predicts $\widehat C = Q_t$, so

$$
A_\mathrm{loc}^\star = p.
$$

A temporal method can exceed this by aggregating repeated independent noisy
copies. For binary $K = 2$ and an odd window size $W$, the majority-vote
oracle has accuracy

$$
A_\mathrm{oracle}(W) = \sum_{r=(W+1)/2}^{W} \binom{W}{r}\, p^r\, (1-p)^{W-r}.
$$

For general $K$, the oracle is the maximum-likelihood estimate of $C$ from
the symbol counts in the window.

### 4.4 Non-factorization proof

Even though each one-token marginal is uniform over $[K]$, the joint
distribution does not factorize. Let $r = (1-p)/(K-1)$. Then

$$
\mathbb P(Q_t = Q_{t'} \mid t \neq t') = p^2 + (K-1)\, r^2.
$$

If tokens were independent with uniform marginals, this probability would
be $1/K$. Since $p^2 + (K-1) r^2 > 1/K$ whenever $p \neq 1/K$, the process
is not a product distribution over tokens.

### 4.5 Worked example

Take $K = 2$ and $p = 0.75$. A single token is correct with probability
$0.75$, so $A_\mathrm{loc}^\star = 0.75$. With $W = 3$, majority vote is
correct if at least two of three noisy copies are correct:

$$
A_\mathrm{oracle}(3) = 0.75^3 + 3(0.75)^2(0.25) = 0.84375.
$$

The non-factorization is also visible:

$$
\mathbb P(Q_1 = Q_2) = 0.75^2 + 0.25^2 = 0.625,
$$

whereas two independent fair bits would agree with probability $0.5$.

### 4.6 Preregistered predictions

| Architecture | Prediction |
|---|---|
| Per-token SAE | Recovers local alphabet directions but cannot exceed $A_\mathrm{loc}^\star = p$ from a single-token code. |
| Mean-pool temporal baseline | Strong; close to oracle when noise is moderate and $W$ is large. |
| Vanilla TXC / TXCDR | Strong; expected to behave like a smoother and match mean-pool baselines. |
| T-SAE / TFA | Should help if they aggregate stable evidence; exact ranking is empirical. |
| Frequency-split TXC (DC branch) | Strong — DC branch should carry most of the probe signal. |
| Frequency-split TXC (AC branch) | Weak — nonzero-frequency branches should contribute little, because the signal is DC. |

## 5. Benchmark 2: AC-only high-frequency signed motion

### 5.1 Process definition

This task is designed so that mean-pooling destroys the signal. Let $M$ be
an odd integer and let $v \in \mathbb Z_M$ be a high-frequency step — for
example $v = (M-1)/2$. Let

$$
S \sim \mathrm{Unif}(\{-1, +1\}), \qquad B \sim \mathrm{Unif}(\mathbb Z_M).
$$

The emitted symbol is

$$
Q_t = B + S\, v\, t \pmod M.
$$

The activation is $x_t = u_{Q_t} + \sigma\, \epsilon_t$.

The hidden label is the signed velocity $S$. Consecutive symbols determine
it:

$$
Q_{t+1} - Q_t = S\, v \pmod M.
$$

The signal lives in the ordered difference between tokens, not in the
temporal mean.

### 5.2 HMM

The hidden state is $h_t = (S, Q_t) \in \{-1,+1\} \times \mathbb Z_M$, with
deterministic transitions

$$
Q_{t+1} = Q_t + S\, v \pmod M.
$$

The emitted symbol at time $t$ is $Q_t$. In edge-emitting form, for each
$a \in \mathbb Z_M$,

$$
T^{(a)}_{(s,q),(s',q')}
= \mathbf 1\{s' = s\}\, \mathbf 1\{a = q\}\, \mathbf 1\{q' = q + s v \pmod M\}.
$$

The initial distribution is uniform over $S$ and $Q_0$.

### 5.3 Local ceiling

For either sign $s$, $Q_t = B + s\, v\, t \pmod M$. Since $B$ is uniform
over $\mathbb Z_M$, the conditional marginal is also uniform:

$$
Q_t \mid S = s \sim \mathrm{Unif}(\mathbb Z_M).
$$

Therefore $I(S; Q_t) = 0$ and the one-token Bayes accuracy is

$$
A_\mathrm{loc}^\star = \tfrac{1}{2}.
$$

This is a statement about the full input distribution, *not* about linear
decoding. If an encoder computes any representation $Z = \phi(x_t)$, then
$S \to Q_t \to x_t \to Z$ is a Markov chain. Because $I(S; Q_t) = 0$ and
the observation noise/magnitudes do not depend directly on $S$, the
data-processing inequality gives

$$
I(S; Z) = 0.
$$

**No nonlinear single-token encoder can beat the ceiling**, regardless of
SAE width or sparsity. This is the tight architectural impossibility result
that the existing coupled-HMM bench lacks.

### 5.4 Non-factorization proof

Conditioned on $S = s$, the event $Q_{t+1} = Q_t + s\, v \pmod M$ has
probability $1$. If the tokens factorized with uniform one-token marginals,
this event would have probability $1/M$. Since $1 \neq 1/M$, the process is
not a product distribution over tokens.

### 5.5 Worked example

Take $M = 7$ and $v = 3$. If $B = 2$ and $S = +1$:

$$
Q_0, Q_1, Q_2, Q_3 = 2, 5, 1, 4.
$$

If $B = 2$ and $S = -1$:

$$
Q_0, Q_1, Q_2, Q_3 = 2, 6, 3, 0.
$$

A single observation such as $Q_0 = 2$ tells us nothing about $S$ — the
random starting phase could have produced any symbol under either sign.
But two consecutive observations reveal the sign:

- If $Q_1 - Q_0 = 3 \pmod 7$, then $S = +1$.
- If $Q_1 - Q_0 = -3 = 4 \pmod 7$, then $S = -1$.

### 5.6 Preregistered predictions

| Architecture | Prediction |
|---|---|
| Per-token SAE | At chance for $S$ under a single-token probe; may recover alphabet directions $u_a$. |
| Mean-pool temporal baseline | Fails (near chance), because the label is in an ordered difference. |
| Vanilla TXC / TXCDR | May recover some signal if it learns zero-mean filters, but expected to be weaker than on DC tasks. |
| T-SAE / TFA | Should beat mean-pooling only if attention/filtering learns the ordered motion rather than smoothing. |
| Frequency-split TXC (AC branch) | Strong, because the correct statistic is a high-pass difference. |
| Frequency-split TXC (DC branch) | At chance, since DC erases sign. |
| Localized convolutional temporal model | Strongest predicted architecture: can represent a signed transition at a temporal center. |

## 6. Benchmark 3: mixed ten-frequency cyclic HMM

### 6.1 Process definition

The main frequency-response benchmark. Let $M$ be a large prime or odd
integer, and choose ten velocities

$$
\Omega = \{\omega_1, \ldots, \omega_{10}\} \subset \mathbb Z_M.
$$

A concrete default is

$$
M = 101, \qquad
\Omega = \{0, 1, 2, 4, 8, 16, 24, 32, 40, 50\}.
$$

The value $0$ is DC; small nonzero values are low frequency; values near
$M/2$ are high frequency. Sample

$$
Y \sim \mathrm{Unif}(\Omega), \qquad
B \sim \mathrm{Unif}(\mathbb Z_M),
$$

and emit

$$
Q_t = B + Y\, t \pmod M.
$$

The activation is $x_t = u_{Q_t} + \sigma\, \epsilon_t$. The hidden label
$Y$ is the temporal frequency / velocity.

### 6.2 HMM

The hidden state is $h_t = (Y, Q_t) \in \Omega \times \mathbb Z_M$, with
transitions

$$
Q_{t+1} = Q_t + Y \pmod M, \qquad Y_{t+1} = Y_t.
$$

For emitted symbol $a \in \mathbb Z_M$, the edge-emitting transition is

$$
T^{(a)}_{(y,q),(y',q')}
= \mathbf 1\{y' = y\}\, \mathbf 1\{a = q\}\, \mathbf 1\{q' = q + y \pmod M\}.
$$

The initial distribution is uniform over $Y \in \Omega$ and
$Q_0 \in \mathbb Z_M$.

### 6.3 Local ceiling

For any fixed $y \in \Omega$, $Q_t = B + y\, t \pmod M$ and $B$ is uniform,
so $Q_t \mid Y = y \sim \mathrm{Unif}(\mathbb Z_M)$. Hence the one-token
marginal is identical for all ten frequencies:

$$
\mathbb P(Q_t = a \mid Y = y) = \tfrac{1}{M}.
$$

Therefore $I(Y; Q_t) = 0$ and, if $Y$ is uniform over the ten frequencies,

$$
A_\mathrm{loc}^\star = \tfrac{1}{10}.
$$

This ceiling applies to any nonlinear single-token encoder by data
processing (same argument as §5.3).

### 6.4 Non-factorization proof

The joint distribution contains the deterministic temporal constraint
$Q_{t+1} - Q_t = Y \pmod M$, which holds with probability $1$ conditioned
on $Y$. If tokens factorized with uniform marginals, this event would have
probability $1/M$, so the process does not factorize.

### 6.5 Worked example

Take $M = 31$ and a ten-frequency subset

$$
\Omega = \{0, 1, 2, 3, 4, 7, 8, 11, 13, 15\}.
$$

If $B = 6$ and $Y = 4$, then

$$
Q_0, Q_1, Q_2, Q_3, Q_4 = 6, 10, 14, 18, 22 \pmod{31}.
$$

The single symbol $Q_0 = 6$ is just a random phase — it says nothing about
$Y$. But the pair $(Q_0, Q_1)$ gives $Y = Q_1 - Q_0 = 4 \pmod{31}$.

In the noiseless symbolic process, two consecutive emissions identify the
frequency. In the noisy activation process, the raw-window oracle first
decodes local symbols and then computes the difference.

### 6.6 Frequency-response metric

For each frequency $\omega \in \Omega$, compute

$$
A(\omega) = \mathbb P(\widehat Y = Y \mid Y = \omega),
$$

then normalize by the local ceiling $1/10$:

$$
S(\omega) = \frac{A(\omega) - 1/10}{1 - 1/10}.
$$

Plotting $S(\omega)$ against $\omega$ gives the architecture's empirical
frequency response.

### 6.7 Preregistered predictions

| Architecture | Prediction |
|---|---|
| Per-token SAE | At the one-token ceiling $1/10$ for $Y$; should still recover local alphabet directions. |
| Stacked SAE + nonlinear / symbolic oracle | Can recover $Y$ from full windows; this measures information in the window, not whether the dictionary learned temporal features. |
| Stacked SAE + fixed linear probe | Expected to remain limited on modular differences unless the probe class is enriched. |
| Mean-pool temporal baseline | High response at $\omega = 0$ and possibly very low frequencies; poor at high frequencies. |
| Vanilla TXC / TXCDR | Predicted low-pass response: strong at DC/low frequencies, decaying as $\omega$ increases. |
| T-SAE / TFA | Empirical. If attention smooths, low-pass; if it learns ordered phase relations, may recover mid/high frequencies. |
| DC/AC-split TXC | DC branch recovers $\omega = 0$; AC branch recovers nonzero modes. |
| Multi-band frequency TXC | Should give the flattest response curve if branch budgets are sufficient. |
| Localized convolutional TXC | Strongest for high-frequency and phase-localized modes. |

## 7. Frequency-split temporal architectures

### 7.1 DC/AC-split TXC

The simplest architectural modification splits the model into a DC branch
and an AC branch.

The **DC branch** uses time-constant kernels:

$$
p_j^{\mathrm{DC}}(X) =
\left\langle e_j,\; \tfrac{1}{W} \sum_{\tau=0}^{W-1} x_\tau \right\rangle.
$$

The **AC branch** uses zero-mean temporal kernels:

$$
p_j^{\mathrm{AC}}(X) = \sum_{\tau=0}^{W-1} \langle e_{j,\tau}, x_\tau \rangle,
\qquad
\sum_{\tau=0}^{W-1} e_{j,\tau} = 0.
$$

The two branches receive separate sparsity budgets $k_\mathrm{DC},
k_\mathrm{AC}$, preventing the smoothing branch from monopolizing capacity.
Preregistered prediction: the DC branch wins on the DC-only benchmark, the
AC branch wins on the AC-only benchmark, and both matter on mixed-frequency
data.

### 7.2 Multi-band frequency TXC

Choose frequency bands $B_0 = \{\mathrm{DC}\}, B_1 = \text{low},
B_2 = \text{mid}, B_3 = \text{high}$ — or one band per benchmark frequency.
For branch $b$, constrain encoder kernels to lie in the corresponding
temporal band:

$$
e^{(b)}_{j,\tau} =
\sum_{\omega \in B_b} \widehat e^{(b)}_j(\omega)\, \psi_\omega(\tau).
$$

The branch preactivation is

$$
p_j^{(b)}(X) = \sum_{\tau=0}^{W-1} \langle e^{(b)}_{j,\tau}, x_\tau \rangle.
$$

Each branch has its own sparsity budget $k_b$, and the final reconstruction
is the sum over branches. Prediction: this should produce an interpretable
decomposition

$$
\widehat X = \widehat X_\mathrm{DC} + \widehat X_\mathrm{low}
+ \widehat X_\mathrm{mid} + \widehat X_\mathrm{high},
$$

and on the ten-frequency benchmark should yield a flatter response curve
than vanilla TXC.

### 7.3 Frequency-regularized TXC

A softer alternative is *not* to hard-constrain the branches. Train a
standard TXC and penalize off-band energy. Assign each atom $j$ to a band
$B(j)$ and add

$$
\mathcal L_\mathrm{band} = \lambda
\sum_j \sum_{\omega \notin B(j)} \|\widehat e_j(\omega)\|^2.
$$

Alternatively, encourage each atom to specialize to a small number of
temporal frequencies by penalizing the entropy of its frequency profile:

$$
\mathcal L_\mathrm{entropy} = \lambda \sum_j H(\mathrm{FreqFrac}_j).
$$

This version may be easier to optimize than hard constraints, but its
learned decomposition is less clean.

### 7.4 Localized convolutional temporal dictionary

Some high-frequency features are not just high-frequency; they are
*localized events*. A scalar window-level TXC produces one activation per
atom per window — it can say that a pattern exists somewhere in the window,
but it is awkward for saying *where* the pattern occurs.

A localized convolutional temporal dictionary uses

$$
z_{t,j} = \mathrm{TopK}_j\!\left(
\sum_{\delta=-r}^{r} \langle e_{j,\delta}, x_{t+\delta} \rangle + b_j
\right),
$$

and decodes by placing a temporal template around the centre:

$$
\widehat x_s = \sum_{t,j} z_{t,j}\, d_{j,\, s-t}.
$$

For a two-token edge, the ideal filter has

$$
e_{j,-1} = -v_j, \qquad e_{j,0} = +v_j.
$$

Prediction: this architecture should dominate on AC-only signed motion and
other localized high-frequency benchmarks.

## 8. Diagnostics shared across all tasks

**Frequency profile.** For every learned atom, compute
$\mathrm{FreqFrac}_j(\omega)$. This is meaningful for architectures with
explicit temporal kernels. For architectures without explicit kernels, one
can estimate an input-gradient frequency profile or simply rely on the
task-level response curve.

**Band ablations.** Project learned kernels into a frequency band $B$:

$$
e_{j,\tau} \leftarrow
\sum_{\omega \in B} \widehat e_j(\omega)\, \psi_\omega(\tau).
$$

Evaluate after projecting to DC, low, mid, and high bands. If performance
survives only under DC projection, the model is a smoother. If performance
survives under nonzero-frequency projection, it learned temporal filters.

**Shuffle and reversal sensitivity.** Compare features on $X$, a within-
window shuffle of $X$, and the reversed window. A smoother is insensitive
to order. A genuine temporal filter should change under shuffle or reversal.

## 10. Interpretation

FrequencyBench is intended to turn a vague statement — *"this architecture
uses temporal context"* — into a concrete characterization: **which
temporal modes does it recover?**

- A model that wins on the DC-only task may simply be a good smoother.
- A model that wins on the AC-only task has learned a genuine
  order-sensitive filter.
- A model that performs well across the ten-frequency ladder has broad
  temporal frequency response.

The desired final figure is a family of frequency-response curves, one per
architecture. We expect current windowed TXCs to look mostly low-pass,
while frequency-split and localized temporal dictionaries should recover a
broader spectrum.

This gives a general narrative that applies not only to TXC, but to T-SAE,
TFA, stacked SAEs, and future temporal architectures.
