# Camera-ready manuscript audit

Audited 2026-09-27 against the Overleaf checkout at `b27b3fc`, chiefly `paper/main_neurips.tex`, `paper/appendix.tex`, `paper/checklist.tex`, and `paper/refs.bib`. This is a read-only manuscript audit: no paper text, figures, or experiments were changed. Line numbers below refer to that snapshot. Review issues are grouped by scientific consequence rather than reviewer score. Rebuttal-result provenance and figure reproduction are handled in the neighboring audit documents.

The paper's defensible contribution is a simple cross-position dictionary architecture plus a benchmark that exposes different architectures' strengths and failures. The camera-ready should make that case with the complete rebuttal evidence and clearly specified controls; the current abstract still promises broader superiority than the body establishes.

## Highest-priority changes using existing results

1. **Replace the headline superiority claims with the complete evidence.** `main_neurips.tex:91` still says TXCs beat conventional and temporal architectures in both synthetic settings and two of four real-world settings, and detect backtracking at a “40% higher rate.” Yet the Coupling result ties T-SAE at 0.99 (`main_neurips.tex:750`), and MLC leads sparse probing at 0.907 (`main_neurips.tex:1120`). The C7 table gives PR-AUC 0.242 for TXC-pro at batch 256 versus 0.175 for TopK SAE at batch 1024, a 38.3% relative PR-AUC difference, not a detection-rate improvement; at matched batch 1024 the TXC-pro value is 0.222, a 26.9% relative difference (`appendix.tex:489–495`). Integrate the rebuttal seed results first, then regenerate abstract, captions, tables, and summary graphic from the same selected cells. Report absolute metrics and differences, with the architecture, seed coverage, batch size, and feature budget attached. The existing 15% inducement claim also needs an explicit denominator and metric. Overlapping marginal confidence intervals alone neither establish nor refute a paired difference: calculate the contrast itself from matched questions or folds.

2. **Separate behavioral control from improved reasoning.** The main text calls TXC-base the strongest causal inducement method (`main_neurips.tex:1141,1147`), but the appendix's peak-steering table gives its batch-1024 configuration a corrected net rescue count of −7 on 61 questions (`appendix.tex:544`); the batch-1024 TXC-pro configuration produces 50 incoherent continuations out of 61 at its peak (`appendix.tex:568`). These numbers are already disclosed, so the needed change is prominence and interpretation. Put coherent backtracking, answer accuracy or net rescues, and count-based inducement together. Describe the intervention as increasing a judged behavior, and avoid suggesting that this improves reasoning unless a separately validated metric supports that claim. The optimal magnitude is chosen from the same cohort's grid (`appendix.tex:533`), so its peak estimate is selection-conditioned; acknowledge that or choose magnitude on a disjoint validation split if such a split already exists.

3. **Bring Stacked SAE and the temporal-specific controls into the main comparison.** `main_neurips.tex:356–360` lists three baselines but describes a fourth, MLC, which appears in the results. Stacked is defined only in `appendix.tex:46` as used in C1/C2/C7 and is absent from the main C7 table and architecture list (`appendix.tex:344,489–495`). The proposed mechanism is shared inference over sequence positions, so the main figures should include the completed Stacked control and the completed rebuttal temporal ablations even when they narrow the original claim. MLC's sparse-probe lead already prevents attributing every gain to temporal structure. Distinguish evidence for temporal context, evidence for a shared crosscoder code, and evidence for TXC-pro's extra losses. If a control was incomplete, say so rather than presenting an inferred result.

4. **Use seed variability honestly and consistently.** C7 currently says all headline results use training seed 42 and replication is future work (`appendix.tex:519`), while the checklist says each architecture has two seeds for the case studies including C7 (`checklist.tex:143–146`). Replace these with the actual final run matrix. Question bootstraps, cross-validation folds, and training seeds measure different sources of uncertainty and should have different labels. Show individual seed values where the number of seeds is small, retain failures or rank reversals, and avoid treating “larger than seed variation” (`main_neurips.tex:1120`) as a general statistical significance claim. For sparse probing, calculate the area summary separately for each seed and then summarize those values; propagating per-budget standard deviations (`appendix.tex:154`) loses the covariance between budgets unless that covariance is explicitly retained.

5. **Replace the broad matching claim with a compact, complete architecture/training table.** The fixed-width claim at `main_neurips.tex:362–367` does not imply equal parameters: a dense TXC has roughly `2*T*d*H` encoder/decoder weights versus `2*d*H` for a token SAE. List width per position and total latent dimensions, train/evaluation window, expected sparsity, actual parameter count, optimizer steps, batch unit, token-positions processed, and data cache. Appendix A calls T-SAE's locked width 16,384 (`appendix.tex:46`), C3 says all widths are 18,432 (`appendix.tex:111`), and C7 says all are 32,768 (`appendix.tex:344`); component-specific overrides need to be explicit. TFA at batch 32 is acknowledged only under C3 caveats (`appendix.tex:185`) despite the common batch-1024 statement (`appendix.tex:9`). Its weaker performance should be qualified as performance under the implemented training budget. The batch-256/1024 C7 comparison also changes total examples fourfold at fixed 300,000 steps, so it does not isolate batch size alone as claimed at `appendix.tex:524`.

## Reviewer concerns already partly addressed

- **The dense Coupling degeneracy is now explicit.** `main_neurips.tex:735–742` correctly says that with `n_parents=10` all hidden footprints collapse to one aggregate direction and that this is a stress test, not disentanglement. Preserve that correction. The headline figure and abstract must carry the same distinction; prefer the distinct-footprint `n_parents=5` result as the primary recovery claim and label `n_parents=10` as aggregate recovery. Three-seed synthetic results are already described (`main_neurips.tex:743–744`), so do not claim no seed testing exists anywhere in the paper.
- **Negative tasks are already acknowledged.** EM and HH-RLHF plainly report TXC weaknesses (`main_neurips.tex:1175,1184`). Keep those results in the main narrative. The explanation that temporal aggregation causes the failures remains a hypothesis without the relevant controls.
- **TXC variants have a main-text explanation and numerous appendix links now.** `main_neurips.tex:316–351` specifies the shared latent and sketches the extra objectives, while C3/C7/EM/HH each link to details. Improve precision and citation rather than treating all definitions as absent.
- **Judge limitations are disclosed but weakly supported.** The human reliability check uses only 20 transcripts (`appendix.tex:449`). This is a small validation sample; report its sampling protocol, label prevalence, and uncertainty, and avoid presenting kappa 0.773 as broad validation across all architectures and steering magnitudes.

## Interpretation and novelty changes

The introduction overstates what a tokenwise objective assumes about contextualized residual activations (`main_neurips.tex:104–110`). A token's hidden state can already contain preceding context; the architectural distinction is whether dictionary inference/reconstruction jointly uses several observed positions. Explain that directly. Likewise, the sparse-probing outcome does not establish a general rule that temporal aggregation helps whenever relevant evidence is distributed nearby (`main_neurips.tex:141,1089,1200`); frame this as a hypothesis consistent with some tasks and tested by the rebuttal controls.

The HH-RLHF label “semantic” means only absolute correlation with length difference below 0.2 (`appendix.tex:279–280`), which does not establish semantic interpretability or eliminate nonlinear length confounding. Rename the statistic to “low length correlation” or retain “semantic” as an explicitly operational shorthand. Equal-length subsets, residualizing length, or length-matched pair resampling would strengthen the conclusion if the per-pair feature summaries are available, without new model training. The main comparison also contrasts T-SAE `k=20` with a much higher window budget in some cells (`main_neurips.tex:1184`); make the matched-budget comparison the headline.

Autointerpretation currently supports a qualitative inventory, not a validated comparison of interpretability. The exclusive activation-map selection forces distinct token-feature assignments (`appendix.tex:722–729`), so diagonal bands should not be treated as independent proof of semantic temporal features. The statement that a silhouette of +0.01 demonstrates well-separated clusters is incorrect (`appendix.tex:691`); near-zero silhouette provides little separation evidence. A few explicit, held-out examples with the same text shown for SAE, Stacked, T-SAE, and TXC would be more informative than a UMAP of generated labels. Such a figure needs example provenance and a declared selection rule to avoid cherry-picking.

The title still begins “Crosscoding Through Time” (`main_neurips.tex:55`). Bayazit, Mueller, and Bosselut already use that exact leading title for checkpoint-axis crosscoding; their paper is now in [ACL 2026](https://aclanthology.org/2026.acl-long.60/). Cite and distinguish it, and consider a title beginning “Temporal Crosscoders” to make the sequence-position contribution discoverable. The prior work does not itself refute novelty on the sequence axis, so narrow the novelty claim to that axis rather than implying the prior paper studies the same operation.

Matryoshka is used without citing its original work (`main_neurips.tex:348`, `appendix.tex:37–43`), despite a bibliography entry at `refs.bib:1617`. Cite the published [ICML 2025 Matryoshka paper](https://proceedings.mlr.press/v267/bussmann25a.html). Also cite and describe the medical dataset/LoRA and the actual SAE-arditi implementation: relevant entries exist at `refs.bib:3319–3350` but are not cited by the live main/appendix text. The Wang entry has a stale author list compared with the [ICLR 2026 paper](https://openreview.net/pdf?id=yjrVOxjkDR). Update conference versions for [SAEBench, ICML 2025](https://proceedings.mlr.press/v267/karvonen25a.html) and [Priors in Time, ICLR 2026](https://openreview.net/pdf?id=4J2e3nWiC8), and reconcile the two T-SAE entries (`refs.bib:94` and `refs.bib:3399`) before regenerating the bibliography. Verify the implemented prior version when published terminology changes rather than silently relabeling an implementation.

## Visual overhaul with scientific purpose

1. **Architecture overview:** replace the crowded three-part overview with a dimensionally explicit schematic comparing per-token SAE, independent Stacked SAEs, and one shared TXC window code. Use the same tokens and residual dimensions in each. Mark which edges share a latent, which weights are position-specific, and what changes in TXC-pro. These are vector diagrams and need no experiments.
2. **Synthetic recovery:** give Denoising and Coupling separate panels, preserve natural metric units, plot seed points, and separate distinct-footprint recovery from the degenerate aggregate stress test. Draw a tiny generative diagram with a sticky hidden chain and noisy emissions so the two ground truths are visually clear.
3. **Sparse probing:** retain the full baseline set, use consistent architecture colors, and show seed-aware curves plus an explicit task aggregation. A small separate TFA panel or an overview-plus-zoom avoids silently dropping it for scale. Per-task differences can show where the small aggregate gain actually comes from.
4. **Backtracking:** replace best-cell-only bars with seed points and paired contrasts; present PR-AUC, inducement, and coherence/accuracy as separate quantities. Include Stacked and the relevant matched-batch cells. A token-aligned example should show observed activations and the actual behavioral reversal, with selected examples clearly labeled.
5. **Cross-task summary:** prefer a compact score table or aligned dot panels to a rose chart that combines different metrics. If the rose remains, expose each axis's normalization and uncertainty. Keep a stable architecture-to-color mapping, use marker/line-style differences as a second channel, and distinguish architecture identity from experimental conditions such as batch size.

Every final plotted mark should have a row in a small source table containing run ID, architecture, seed, training/evaluation protocol, metric, task/cohort, and aggregation. Legends and text should be generated from that same table. This makes a later palette or layout change cheap and protects against reintroducing a superseded best-cell claim.

## Work that is optional rather than a camera-ready prerequisite

Integrating completed rebuttal experiments, repairing the contradictions above, recalculating statistics from saved rows, and rebuilding figures are the first pass. None requires pulling activation caches or retraining language models. A larger blinded judge check on saved transcripts and a length-controlled HH reanalysis can be relatively inexpensive if the required small per-example outputs exist.

New model/dataset replications, longer temporal windows, broad hyperparameter sweeps, and full compute-matched retraining are future-work scope unless a strong retained claim depends on them. A targeted TXC-pro factorial ablation (base, +Matryoshka, +contrastive, both, fixed context and budget) is valuable if not already completed in rebuttal, but the paper can instead honestly present TXC-pro as a compound variant whose individual improvements are not identified. Likewise, temporal shuffling or context removal controls should be incorporated if already run; otherwise narrow the causal-mechanism claim or run a small controlled benchmark with fixed training/evaluation semantics rather than an extensive new sweep.

Finally, the source remains in preprint mode (`main_neurips.tex:3`) with an anonymous code link (`main_neurips.tex:91`). The local style supports `[final]` (`paper/neurips_2026.sty:24–27`). Apply the actual camera-ready instructions, public repository reference, final author metadata, and a rendered PDF/citation/figure audit after the scientific edits; do not assume acceptance alone determines every final-format requirement.
