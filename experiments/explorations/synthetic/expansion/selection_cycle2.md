## Tie-break between the four frozen C1 cards (2 slots)

All four sit in empty cells, so under-coverage alone doesn't order them. Two
deterministic tie-breaks, applied in order:

1. **Maximize class coverage per cycle:** picking one *periodic* and one
   *long-memory* card touches both remaining under-covered classes; picking two
   of the same class would leave one class empty another full cycle.
2. **Avoid same-label-stream duplication within a domain:** the new C2 cards
   already label near-identical streams to two frozen cards —
   `self-reference-echo` ≈ `goal-restatement-recurrence` (problem-goal
   re-anchoring sentences, reasoning) and `list-item-parallelism` ≈
   `enumeration-cadence` (enumerator sentences, text). Selecting those frozen
   cards this cycle would double-spend labeling on ~the same signal; they stay
   frozen for Cycle 3 (where their *distinct statistics* — renewal tail /
   spectral cadence — can still be calibrated, ideally sharing labels).

Hence: reasoning takes the periodic card (`computation-verification-alternation`),
text takes the long-memory card (`pronoun-referent-recurrence`).
