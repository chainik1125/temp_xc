## 0. Identity
- **Property:** Explicit arithmetic/logic error-detection sentences self-excite: catching one error raises the near-future rate of catching more (correction cascades), distinct from strategic backtracking.
- **Ledger cell:** domain = `reasoning-trace` · temporal-class = `bursty/self-exciting`
- **Why it's not already covered:** Backtracking (strategy-switch) is SPEC'd, but error-DETECTION (a mistake in a specific computation) is a distinct event class; tests whether local error-catching clusters independently of strategy switches.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Detecting a concrete computational error should trigger re-checking that surfaces further errors, giving self-excitation. Unlike backtracking (abandoning an approach), this is local recomputation clustering, so ACF(1)>0 and Fano>1 for the error-detection indicator.
- **What would make it ABORT:** Error-detection events are iid (Fano ~1, ACF~0) OR they perfectly co-occur with backtracking (not a distinct axis — redundant with SPEC).
- **Composition risk:** medium + harder problems have more errors (across-trace composition), but clustering within trace is order structure N1 kills.

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): Sentence explicitly identifies a concrete mistake in a specific prior computation/statement.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label one sentence in a reasoning trace. Output 1 if it explicitly identifies a CONCRETE ERROR in a specific prior computation or statement — a wrong number, a miscalculation, a mis-applied rule. Output 0 otherwise. Do NOT mark general strategy changes without an identified error. Examples: 'Wait, 7 times 8 is 56, not 54, I made an error.' -> 1. 'That step is wrong because I forgot the negative sign.' -> 1. 'Let me try a different method.' -> 0 (strategy switch, no concrete error). 'Adding these gives 12.' -> 0. Use context to confirm a specific prior value/step is being corrected.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Regex: /(that('?s| is) wrong|made an? (error|mistake)|miscalculat|should be \d+ not \d+|forgot the|incorrect(ly)?|error in)/i -> 1.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

The unit of time is the sentence index within a trace. Pinned at results/c7_backtracking/stage_a/sentence_labels.json.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** ACF(1..5) of error indicator; Fano factor over windows; inter-error gap CV
- **Expected signature:** ACF(1)>0 and Fano>1 (clustering). N2 keeps any position trend but destroys clustering -> Fano drops to ~1; N3 iid gives ACF~0. Also compute mutual information with backtracking indicator to prove distinctness.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = error base rate; oracle = inter-judge agreement. Floor: all-0 accuracy = 1 - baserate.

## 6. Predictions per architecture (blind — no arch is run this cycle)

- window families (TXC-pre/-post/Stacked/Spectral): Short causal windows capture self-excitation best; matches Hawkes-like character.
