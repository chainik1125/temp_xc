## 0. Identity
- **Property:** Sentences containing quotation/attributed-speech cluster: once a document enters a quoted passage, nearby sentences also carry quotes (self-exciting).
- **Ledger cell:** domain = `text-corpus` · temporal-class = `bursty/self-exciting`
- **Why it's not already covered:** bursty/self-exciting in text-corpus is empty (only reasoning has backtracking); probes clustering of quotation, a lexical/structural burst.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Direct quotation comes in stretches — interview blocks, dialogue, cited passages — so a quote raises the near-future quote rate. This predicts ACF(1)>0 and Fano>1 for the quotation indicator, driven by within-doc ordering rather than doc-level quote density.
- **What would make it ABORT:** Quotation events are iid within doc (Fano~1) OR clustering is entirely explained by whole-doc composition (some docs are all-dialogue) — N1 collapses the effect.
- **Composition risk:** medium + interview/news docs are quote-dense (composition), but within-doc bursting is order structure N1 removes; report observed vs N1 Fano.

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): Sentence contains a direct quotation or reported/attributed speech.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label one sentence from a web document. Output 1 if it contains a DIRECT QUOTATION or clearly attributed speech — words presented as spoken/written by someone, typically in quote marks or with a speech verb ('said', 'stated', 'according to'). Output 0 otherwise. Examples: 'She said, "We will not back down."' -> 1. 'According to the report, growth slowed sharply.' -> 1. 'The company grew rapidly last year.' -> 0. Judge the single sentence.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Match presence of paired quote chars (" " or “ ”) OR speech-verb regex /(said|says|stated|according to|told|remarked|noted that|claimed)/i -> 1.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 400 English web documents sampled from HuggingFaceFW/fineweb (sample-10BT, streamed, seed=0), filtered to 60-200 sentences per document, sentence-segmented with a pinned regex splitter. The unit of time is the sentence index within a document. Pinned at experiments/explorations/synthetic/expansion/data/fineweb_sample.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** ACF(1..5) of quote indicator; Fano factor over windows; inter-quote gap CV
- **Expected signature:** ACF(1)>0, Fano>1. N2 keeps position trend, kills clustering (Fano->1); N3 gives ACF~0; N1 removes within-doc clustering leaving only doc marginal — must beat N1 to avoid the composition trap.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = quote base rate; oracle = inter-judge agreement (heuristic itself is strong, so use it as a check not the label). Floor: all-0 accuracy.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: Fires reliably on quote punctuation/speech verbs per token; misses burst timing.
- window families (TXC-pre/-post/Stacked/Spectral): Short causal windows capture self-excitation, matching Hawkes-like clustering.

  **Deliberately NOT matched:** the identity/content of the quoted speakers
