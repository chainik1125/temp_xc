## 0. Identity
- **Property:** List-item / parallel-structure sentences match each other in consecutive runs, producing positive self-match ACF from template-matching (same structural role adjacent)
- **Ledger cell:** domain = `text-corpus` · temporal-class = `interaction/equality`
- **Why it's not already covered:** interaction/equality empty for text-corpus; template-match runs (parallelism) as a cross-position signature never tested

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Enumerations and parallel constructions produce runs of sentences sharing the same structural template ('First... Second... Third...', bullet-like clauses). Consecutive same-role positions MATCH by structural template, giving positive lag-1 self-match ACF that permutation destroys. This is a match pattern grounded in structural equality between positions, distinct from periodic cadence (which is about spacing) and from bursty content excitation.
- **What would make it ABORT:** self-match ACF(1) indistinguishable from N1 (list-items are marginally frequent but not run-clustered by order)
- **Composition risk:** low — run-clustering of template matches is an order statistic; per-doc rate handled by N1

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): sentence is a list item or parallel-template unit (leading ordinal/enumerator, or a short parallel clause of the form the surrounding list uses) judged from its own form
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label ONE sentence from its OWN wording/form only — no context. Output 1 if the sentence looks like a list item or parallel enumerated unit: it begins with an ordinal or enumerator ('First,', 'Second,', 'Next,', 'Finally,'), a bullet/number marker, or is a short parallel-structured clause typical of a list ('- Fast shipping', 'Add two cups of flour.'). Output 0 for ordinary connected prose sentences that are not list-formatted ('The economy grew steadily over the decade.'). Judge on FORM, not meaning. Examples: 'First, preheat the oven to 350 degrees.' -> 1. 'This development changed the industry forever.' -> 0. 'Next, add the eggs one at a time.' -> 1. Answer with only 0 or 1.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: import re
ENUM = re.compile(r'^\s*(\d+[.)]|[-*•]|first|second|third|fourth|next|then|finally|lastly)\b', re.I)
IMP = re.compile(r'^\s*[A-Z][a-z]+\s+(the|a|an|your|two|one|these)\b')
def label(s):
    if ENUM.match(s):
        return 1
    if IMP.match(s) and len(s.split()) < 12:
        return 1
    return 0
# expect base rate ~8-30%
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** acf1; fano
- **Expected signature:** positive self-match ACF and Fano>1 (clustered runs) beat N1/N2; N1 flattens ACF, exposes run structure
