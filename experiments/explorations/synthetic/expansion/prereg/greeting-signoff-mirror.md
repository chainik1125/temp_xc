## 0. Identity
- **Property:** Direct-address/second-person sentences recur symmetrically near document start and end, producing an echo/anti-symmetric match pattern in the label stream
- **Ledger cell:** domain = `text-corpus` · temporal-class = `interaction/equality`
- **Why it's not already covered:** interaction/equality empty for text-corpus; positional echo/mirroring of a discourse role never probed

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Web documents often open and close by addressing the reader ('welcome', 'if you have questions contact us'), so direct-address sentences are not positionally iid — they echo across the document, matching each other at long lag. The cross-position signature is elevated MI between distant same-role positions and a positive long-lag self-match beyond what marginal rate gives. This is a match/echo structure, distinct from any monotone drift.
- **What would make it ABORT:** self-match MI at lag>1 indistinguishable from N2 (address sentences are position-conditional trend only, no genuine echo)
- **Composition risk:** medium — address density varies by document genre; echo must beat N2 position-conditional

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): sentence directly addresses the reader in second person or issues a reader-directed call ('you', 'contact us', 'subscribe', imperative to reader)
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label ONE sentence from its OWN wording only, no context. Output 1 if the sentence directly addresses the reader: it uses 'you/your' referring to the reader, invites contact/subscription, or is a reader-directed call to action ('If you have any questions, feel free to reach out.', 'Subscribe to our newsletter for updates.', 'Thank you for visiting our site.'). Output 0 for ordinary informative/narrative prose that does not address the reader ('The bridge was completed in 1932.', 'Photosynthesis converts light into energy.'). Note: 'you' inside a general statement ('you cannot buy happiness' as a proverb) still counts as address -> 1. Answer with only 0 or 1.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: import re
ADDR = re.compile(r'\b(you|your|yourself)\b', re.I)
CTA = re.compile(r'\b(contact us|subscribe|sign up|click here|reach out|feel free|thank you for|welcome to|follow us)\b', re.I)
def label(s):
    if CTA.search(s):
        return 1
    if ADDR.search(s):
        return 1
    return 0
# expect base rate ~15-40%; cap check needed
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** mi1; acf1
- **Expected signature:** lag-1 and long-lag self-match MI beats N1 AND N2; N2 captures start/end trend so surviving MI is genuine echo, not position
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
