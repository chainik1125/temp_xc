# Preregistration — `goal-restatement-recurrence`  (FROZEN 2026-07-13, before any data)

## 0. Identity
- **Property:** The reasoner re-states or re-anchors to the original problem goal at renewal intervals far beyond short lags.
- **Ledger cell:** domain = `reasoning-trace` · temporal-class = `long-memory`
- **Why it's not already covered:** long-memory / renewal in reasoning-traces is empty; probes heavy-tailed recurrence of goal-anchoring rather than local self-excitation (backtracking).

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Goal restatements should recur as a renewal process with heavy-tailed inter-event gaps: the model re-grounds sporadically after long stretches of local computation. Unlike bursty backtracking, these are spaced-out anchors, so the inter-event distribution should have a tail heavier than geometric.
- **What would make it ABORT:** Inter-restatement gaps are geometric/exponential (no heavy tail) OR restatements are confined to trace start (pure position trend killed by N2).
- **Composition risk:** low + goal-restatement is a within-trace timing phenomenon; every trace has a goal so marginal is homogeneous across traces.

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): Sentence explicitly re-states what is being solved / the target quantity / the problem constraints.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label one sentence from a math/logic reasoning trace. Output 1 if the sentence RE-STATES or RE-ANCHORS to the overall problem goal — i.e. it recalls what is being solved, the target quantity, or a given constraint, rather than performing a new computation step. Output 0 otherwise. Examples: 'So we need to find the total number of red marbles.' -> 1. 'Recall the constraint that x must be positive.' -> 1. 'Multiplying both sides by 3 gives 6x.' -> 0. 'Hmm, let me try a different approach.' -> 0. Use the preceding context only to judge whether this is a restatement of the ORIGINAL goal versus a fresh step.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Regex/keyword: lines matching /(we need to|we want to|the problem asks|recall that|goal is|find the|solve for|remember that|going back to the (problem|question))/i, excluding lines with an arithmetic operator token immediately after.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 300 chain-of-thought reasoning traces from DeepSeek-R1-Distill-Llama-8B over math/logic prompts (10 categories x 30), already sentence-segmented: 25,528 sentences, mean 85 sentences/trace (median 91, max 169). The unit of time is the sentence index within a trace. Pinned at results/c7_backtracking/stage_a/sentence_labels.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** inter-event gap distribution (mean, tail index / CV); ACF of the event indicator at lags 1-40; fano factor over windows
- **Expected signature:** Heavy-tailed gaps: CV>1 and slow ACF decay beyond N3 (iid geometric). N2 preserves any start-bias but should not reproduce the long-lag recurrence; N1 destroys the gap structure entirely.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = base rate of restatement sentences (est. ~8-12%); oracle bounded by inter-judge agreement. Provable floor: predicting all-0 gives 1 - baserate accuracy but 0 recall on events.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: Should fire on explicit goal-lexicon tokens; captures marginal well but misses gap-timing since SAE is per-token memoryless.
- window families (TXC-pre/-post/Stacked/Spectral): Wide windows (>=32 sentences) needed to capture heavy-tailed recurrence; short windows underperform, revealing long-memory.

## 7. Mirror (Appendix B), to be fit only if the gate PASSES
- **Process:** `semi_markov`. **Matched param(s):** the heavy-tailed inter-event gap distribution (dwell).
  **Deliberately NOT matched:** any correlation between restatement content and local computation state
