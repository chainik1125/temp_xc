## 0. Identity
- **Property:** Rhetorical/explicit questions are followed by answering sentences in a directed order (question-before-answer), an asymmetry invisible to the marginal.
- **Ledger cell:** domain = `text-corpus` · temporal-class = `AC-order-sensitive`
- **Why it's not already covered:** AC-order-sensitive in text-corpus is empty; probes a directed local dependency (Q→A) whose reverse is implausible, isolating order from composition.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Web prose (FAQs, explainers, blogs) poses questions then answers them; the forward question→answer transition should dominate the reversed one. The marginal question and answer counts are reversal-invariant, so any forward/reverse gap is pure order structure.
- **What would make it ABORT:** Forward and time-reversed Q→A transition rates are equal — questions do not preferentially precede their answers, so no directed order.
- **Composition risk:** low + Q and A both appear across most explanatory docs; the directed adjacency is order, not per-doc rate.

## 2. Labeler
- **Signal:** per-sentence `ordinal` (n_values=3): Whether the sentence is a question (Q), a direct answer/response to a prior question (A), or neither.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label one sentence from a web document. 0 = neither. 1 = QUESTION: poses a question (rhetorical or genuine, typically ends in '?' or is interrogative). 2 = ANSWER: directly answers or responds to a question raised in the preceding context ('The answer is', 'Yes,', 'This is because', a direct resolution). Examples: 'So why does this matter?' -> 1. 'What are the benefits of exercise?' -> 1. 'The main benefit is improved cardiovascular health.' (after a question) -> 2. 'The weather was cold that day.' -> 0. Use preceding context to decide if a statement answers a just-asked question.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Q = sentence ends with '?' or starts with {what, why, how, when, who, is, are, do, does, can}. A = prior sentence was Q and current starts with {yes, no, the answer, this is, because, it is}.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 400 English web documents sampled from HuggingFaceFW/fineweb (sample-10BT, streamed, seed=0), filtered to 60-200 sentences per document, sentence-segmented with a pinned regex splitter. The unit of time is the sentence index within a document. Pinned at experiments/explorations/synthetic/expansion/data/fineweb_sample.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** P(answer at t | question at t-1) forward; same reversed; directed asymmetry index; lag distribution of A after Q
- **Expected signature:** Forward Q→A rate >> reversed. N1 equalizes directions; N3 gives marginal product. Only true ordering preserves the asymmetry.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = modal class; oracle = inter-judge agreement. Floor: modal predictor.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: Detects '?' and interrogative tokens; blind to the cross-sentence answering link.
- window families (TXC-pre/-post/Stacked/Spectral): Backward-looking causal windows outperform symmetric ones, revealing directedness.

- **Process:** `markov`. **Matched param(s):** forward transition matrix over {none,question,answer}.
  **Deliberately NOT matched:** the semantic relevance of the answer to the question
