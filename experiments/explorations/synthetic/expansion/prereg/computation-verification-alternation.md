## 0. Identity
- **Property:** The reasoner alternates rhythmically between forward-computation sentences and verification/checking sentences at a preferred period.
- **Ledger cell:** domain = `reasoning-trace` · temporal-class = `periodic`
- **Why it's not already covered:** periodic in reasoning-traces is empty; probes cyclic compute-then-check rhythm distinct from bursty backtracking.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Reasoning may settle into a compute→compute→check cadence, producing a preferred period in the verification indicator. If real, the event-indicator power spectrum should show a peak at a non-trivial period that survives permutation nulls only through ordering.
- **What would make it ABORT:** No spectral peak (flat spectrum) — verification events are aperiodic/random OR clustered rather than rhythmic, meaning the periodic hypothesis fails though bursty might not.
- **Composition risk:** medium + verification density may vary by problem type (composition across traces), but a within-trace PERIOD is order structure N1 destroys.

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): Sentence checks, verifies, or re-derives a prior result rather than advancing new computation.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label one sentence in a reasoning trace. Output 1 if it VERIFIES or CHECKS a previous result — substituting back, confirming, sanity-checking, or re-deriving to test correctness. Output 0 if it advances NEW computation or reasoning. Examples: 'Let me check: 6 times 7 is 42, correct.' -> 1. 'Plugging x=3 back in: 9-6=3, which matches.' -> 1. 'Now I multiply both sides by 2.' -> 0. 'Next, consider the second case.' -> 0. Use context to tell whether this re-examines an earlier step (1) or moves forward (0).
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Keyword match: /(check|verify|confirm|plug(ging)? back|substitute back|sanity|make sure|does this (match|work)|let('?s| us) verify)/i -> 1.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 300 chain-of-thought reasoning traces from DeepSeek-R1-Distill-Llama-8B over math/logic prompts (10 categories x 30), already sentence-segmented: 25,528 sentences, mean 85 sentences/trace (median 91, max 169). The unit of time is the sentence index within a trace. Pinned at results/c7_backtracking/stage_a/sentence_labels.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** periodogram / Fourier power of event indicator; peak-period location and prominence; ACF for periodic side-lobes
- **Expected signature:** A spectral peak at period p with side-lobe ACF ringing. N1/N2/N3 all yield flat spectra (no preferred period); the ordered periodogram peak is the discriminator.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = base rate of verification sentences; oracle = inter-judge agreement. Floor: all-0 predictor accuracy = 1 - baserate.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: Detects verification lexicon per token but cannot represent a period without positional state; expect it to miss rhythm.
- window families (TXC-pre/-post/Stacked/Spectral): Windows matched to the period p should peak; mismatched window sizes degrade, revealing periodicity.

## 7. Mirror (Appendix B), to be fit only if the gate PASSES
- **Process:** `periodic_rate`. **Matched param(s):** the preferred period and event rate of verification.
  **Deliberately NOT matched:** the content dependence of what gets verified
