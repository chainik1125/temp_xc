## 0. Identity
- **Property:** Sentences performing arithmetic/algebraic manipulation ALTERNATE with sentences asserting a result, producing negative self-match ACF (anti-match)
- **Ledger cell:** domain = `reasoning-trace` · temporal-class = `interaction/equality`
- **Why it's not already covered:** interaction/equality empty; alternation (negative acf1) as a cross-position pattern never tested in reasoning traces

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Manipulation steps and result-assertions do not run in long blocks; a compute step tends to be followed by a 'so we get' assertion, then another compute — an alternation rather than persistence. The cross-position signature is NEGATIVE self-match ACF (anti-match): label_t predicts label_{t+1} to DIFFER. This is a genuine cross-position comparison distinct from bursty persistence and cannot be reduced to marginal rate.
- **What would make it ABORT:** self-match ACF(1) >= 0 or indistinguishable from N1 (no alternation; blocks or random)
- **Composition risk:** low — alternation is intrinsically an order statistic, immune to per-doc rate composition

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): sentence performs an explicit symbolic manipulation (an equation being transformed / a computation carried out) rather than stating a conclusion
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label ONE sentence from its own wording ONLY, with no context. Output 1 if the sentence is carrying out a computation or algebraic manipulation — it shows an operation in progress or an intermediate transform ('multiply both sides by 2', '3 times 4 is 12', 'expanding gives x^2 + 2x'). Output 0 if it instead ASSERTS a conclusion or result ('therefore the answer is 12', 'so x equals 5', 'this means the set is empty') or is non-mathematical prose. Judge by the sentence's grammatical function: doing-the-work vs stating-the-outcome. Examples: 'Adding these two equations eliminates y.' -> 1. 'So the final total is 30.' -> 0. 'Now factor the quadratic.' -> 1. Answer with only 0 or 1.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: import re
OP = re.compile(r'\b(multiply|divide|add|subtract|expand|factor|substitute|simplify|differentiate|integrate|square|combine)\b', re.I)
RESULT = re.compile(r'\b(therefore|so the|thus the|hence|the answer is|this means|we (get|obtain|conclude)|equals?)\b', re.I)
def label(s):
    if RESULT.search(s) and not OP.search(s):
        return 0
    if OP.search(s) or re.search(r'[0-9]\s*[+\-*/=]\s*[0-9]', s):
        return 1
    return 0
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).
