## 0. Identity
- **Property:** Opinion/argumentative web docs cluster sentences by claim-type (assertion, evidence, concession, example) into same-type runs.
- **Ledger cell:** domain = `text-corpus` · temporal-class = `interaction/equality`
- **Why it's not already covered:** Unlike the two binary failures, this is a 5-class rhetorical claim-type label; the measured signature is equality-adjacency of claim-types (evidence-blocks, example-blocks), not any echo or alternation.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Argumentative prose tends to group like rhetorical acts: a run of assertions, then a run of supporting evidence, then an illustrative example block, occasionally a concession. Adjacent sentences therefore share a claim-type well above chance, producing rhetorical segments whose boundaries are claim-type changepoints. The claim-type is inferred from each sentence's own markers, so equality is purely in the measured lag-1 match.
- **What would make it ABORT:** self-match ACF(1) does not exceed the within-doc permutation null N1 — claim-types are sprinkled without contiguous runs.
- **Composition risk:** medium — assertion-claim may dominate; evidence/example/concession markers are distinctive enough to keep three classes above 3%.

## 2. Labeler
- **Signal:** per-sentence `categorical` (n_values=5): the rhetorical claim-type of the single sentence (assertion, evidence-citation, example-illustration, concession-qualifier, or other) from its own markers.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
Label ONE sentence from a web document by its rhetorical claim-type, using ONLY its own wording; never reference neighbouring sentences. Output one integer 0-4. 1 = assertion-claim: states a position or general claim ('Remote work boosts productivity'; 'This policy is fundamentally flawed'). 2 = evidence-citation: presents data, statistics, or a cited source ('A 2020 study found a 30% increase'; 'According to the report'; 'Sales rose by 12%'). 3 = example-illustration: gives a concrete instance ('For example, consider a small business'; 'Take Amazon as a case'; 'Such as when a user logs in'). 4 = concession-qualifier: acknowledges a limit or opposing point ('Admittedly, this has drawbacks'; 'Of course, results may vary'; 'However, critics argue otherwise'). 0 = other. Judge only the sentence shown.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: lower-case. If contains for example|for instance|such as|e.g.|consider a|take .* as -> 3. Elif contains admittedly|of course|however|granted|to be fair|critics|although|while it is true -> 4. Elif contains study|according to|research|[0-9]+%|data|survey|report found|statistics -> 2. Elif contains is |are |should|must|will |fundamentally|clearly|obviously -> 1. Else -> 0. First match in order wins.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 400 English web documents sampled from HuggingFaceFW/fineweb (sample-10BT, streamed, seed=0), filtered to 60-200 sentences per document, sentence-segmented with a pinned regex splitter. The unit of time is the sentence index within a document. Pinned at experiments/explorations/synthetic/expansion/data/fineweb_sample.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** self-match ACF(1) (equality-adjacency); self-match ACF(4); dwell-length CV
- **Expected signature:** real ACF(1) above N1/N2/N3; rhetorical blocks give runs so both N1 and N2 fall clearly below real.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- chance = iid claim-type match rate; oracle = Markov chain over claim-types matching lag-1.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: reads each sentence's claim-type but not block membership; predicts chance-level adjacency.
- window families (TXC-pre/-post/Stacked/Spectral): lag-1 comparison exposes the rhetorical runs and elevated ACF(1).

## 7. Mirror (Appendix B), to be fit only if the gate PASSES
- **Process:** `markov`. **Matched param(s):** 5-state one-step transition matrix over claim-types.
  **Deliberately NOT matched:** run-length dispersion (dwell_cv) not fit by the transition matrix

## 8. Cycle-3 design gates (preregistered in this card)
- **Gate 7 (no-leakage):** categorical per-sentence CONTENT label, every class
  decidable from the sentence's own wording; labeling runs with **zero context
  sentences** (ctx=0). Classes: `0` = other/background; `1` = assertion-claim; `2` = evidence-citation; `3` = example-illustration; `4` = concession-qualifier.
- **Primary statistic (fixed by the C3 recipe):** the equality-adjacency
  `[c_t = c_{t-1}]` — categorical self-match `acf1`, expected sign positive.
  The equality lives in the statistic, never in the label.
- **Gate 8 (non-fitted moment):** the `markov` mirror must also
  reproduce `dwell_cv`
  on held-out draws within the **uniform C3 tolerance: ±20% of the
  held-out real magnitude** (`amend_cards_c3.py` rule; floors apply) —
  A Markov fit implies geometric dwell (CV~1); if real rhetorical blocks are coherent multi-sentence segments the dwell CV departs from geometric, and that departure is not set by the fitted one-step transition probabilities, making it a genuine held-out moment.. Fail ⇒ mirror invalid ⇒ ABORT.
- **Measured-class filing:** if calibration measures this stream as something
  other than multi-class run/segment equality structure (e.g. one class
  dominates and the signature is binary-like self-excitation), the ledger cell
  is assigned by the MEASURED class, not this card's proposal.
