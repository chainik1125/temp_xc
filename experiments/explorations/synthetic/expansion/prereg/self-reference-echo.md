## 0. Identity
- **Property:** Sentences that quote/restate the ORIGINAL problem statement recur at a characteristic lag, producing echo peaks in self-match ACF
- **Ledger cell:** domain = `reasoning-trace` · temporal-class = `interaction/equality`
- **Why it's not already covered:** interaction/equality row empty for reasoning-trace; echo-at-lag is a match structure never probed

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Problem-referencing sentences ('we need to find x', 'the question asks for the area') are not iid: a trace re-anchors to the problem after excursions, so label=1 positions echo each other at a lag rather than clustering. The cross-position signature is a positive self-match ACF that survives permutation only because re-anchoring is order-locked to sub-goal completion. This is a MATCH pattern (same referent class recurring) not mere persistence.
- **What would make it ABORT:** self-match ACF(1) indistinguishable from N1 permutation (echo is just marginal rate, no lag structure)
- **Composition risk:** medium — re-anchoring rate varies by problem length, but echo-lag structure is order-only

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): sentence explicitly refers back to the given problem/question/goal (restates what is asked or the given quantities)
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label ONE sentence using ONLY its own wording — you get NO surrounding context and must not guess what came before. Output 1 if the sentence explicitly refers to the problem being solved: it restates what is asked, names the given quantities, or points to the goal ('we need to find the value of x', 'the problem gives us three coins', 'so the question is asking for the total area'). Output 0 otherwise: pure calculation ('3+4=7'), commentary ('this seems tricky'), or a step that does not name the problem/goal. Examples: 'We are asked to compute the probability that both dice show even.' -> 1. 'Multiplying gives 42.' -> 0. 'So I need to figure out the remainder when divided by 7.' -> 1. Answer with only 0 or 1.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: import re
GOAL = re.compile(r'\b(we (are|were) asked|the (problem|question) (asks|gives|states|wants)|need to (find|compute|determine)|asked to (find|compute)|find the (value|area|probability|number)|what is asked|the goal is)\b', re.I)
GIVEN = re.compile(r'\b(we are given|given that|the given|it is given)\b', re.I)
def label(s):
    if GOAL.search(s) or GIVEN.search(s):
        return 1
    return 0
# base rate expected ~10-25% of reasoning sentences
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** acf1; mi1
- **Expected signature:** positive self-match ACF at short lag beats N1/N2; N3 flat; N1 destroys the echo (keeps rate)
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.
