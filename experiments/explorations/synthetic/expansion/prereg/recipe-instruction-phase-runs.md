## 0. Identity
- **Property:** How-to / recipe web docs organize sentences into functional segments (ingredients, steps, tips, background) forming same-function runs.
- **Ledger cell:** domain = `text-corpus` · temporal-class = `interaction/equality`
- **Why it's not already covered:** Distinct from list-item-parallelism (near-miss re-freeze, item-vs-not binary flavour) and greeting-signoff (mis-keyed mirror): a 5-class functional content label whose equality-adjacency captures multi-sentence functional segments.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Instructional web documents cluster sentences by function — a block describing ingredients/materials, a block of imperative steps, a block of tips/notes, a block of background/context. These blocks are multi-sentence runs, so the functional label repeats across adjacent sentences far above chance. The equality is only in the lag-1 match; each sentence's function is read from its own imperative/nominal form.
- **What would make it ABORT:** self-match ACF(1) lies inside the position-conditional iid band N2 — functions do not segment into contiguous blocks.
- **Composition risk:** medium — many fineweb docs are non-instructional; the 60-200 sentence filter plus other/background class absorbs them, but marginal skew toward class 0 is a risk.

## 2. Labeler
- **Signal:** per-sentence `categorical` (n_values=5): the functional role of the single sentence (background, ingredient/material listing, imperative step, tip/caution, or other) from its own grammatical form.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
Label ONE sentence from a web document by its functional role, using ONLY its own wording — never assume anything about surrounding sentences. Output one integer 0-4. 1 = context-background: explanatory or descriptive prose about why/what ('This dish originates from southern Italy'; 'The technique dates back centuries'). 2 = ingredient-material-listing: names required items/quantities/materials ('2 cups of flour'; 'You will need a screwdriver and two screws'; 'Ingredients: sugar, eggs, butter'). 3 = imperative-step: a command directing an action ('Preheat the oven to 350'; 'Mix the dry ingredients'; 'Tighten the bolt clockwise'). 4 = tip-caution: advice, warning, or optional note ('Be careful not to overmix'; 'For best results, chill overnight'; 'Note: this may vary'). 0 = other. Judge only the sentence shown.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: lower-case, strip. If starts with an imperative verb (preheat|mix|add|stir|tighten|cut|pour|place|remove|combine|heat|set) or matches ^[a-z]+ the -> 3. Elif contains cups?|tbsp|tsp|ingredients|you will need|grams|ounces|materials:|[0-9]+ ?(cup|tablespoon|gram) -> 2. Elif contains be careful|note:|tip:|for best results|make sure|avoid|warning|optionally -> 4. Elif contains originates|history|traditionally|because|this is|known as|dates back -> 1. Else -> 0. First match wins.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 400 English web documents sampled from HuggingFaceFW/fineweb (sample-10BT, streamed, seed=0), filtered to 60-200 sentences per document, sentence-segmented with a pinned regex splitter. The unit of time is the sentence index within a document. Pinned at experiments/explorations/synthetic/expansion/data/fineweb_sample.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** self-match ACF(1) (equality-adjacency); mean run-length; self-match MI(2)
- **Expected signature:** real ACF(1) above N1/N2/N3; blocks give clear runs so N2 (which preserves position marginals) is the discriminating null.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- chance = sum p_c^2 function-match rate; oracle = semi-Markov reproducing block lengths.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: reads the function of each sentence but not the block; predicts near-chance adjacency.
- window families (TXC-pre/-post/Stacked/Spectral): lag-1 comparison recovers block runs and elevated ACF(1).

## 7. Mirror (Appendix B), to be fit only if the gate PASSES
- **Process:** `semi_markov`. **Matched param(s):** empirical block-length (dwell) distribution per function + jump chain.
  **Deliberately NOT matched:** self-match ACF at lag 4 — cross-block memory not fit by lag-1 dwell/jump

## 8. Cycle-3 design gates (preregistered in this card)
- **Gate 7 (no-leakage):** categorical per-sentence CONTENT label, every class
  decidable from the sentence's own wording; labeling runs with **zero context
  sentences** (ctx=0). Classes: `0` = other/background; `1` = context-background; `2` = ingredient-material-listing; `3` = imperative-step; `4` = tip-caution.
- **Primary statistic (fixed by the C3 recipe):** the equality-adjacency
  `[c_t = c_{t-1}]` — categorical self-match `acf1`, expected sign positive.
  The equality lives in the statistic, never in the label.
- **Gate 8 (non-fitted moment):** the `semi_markov` mirror must also
  reproduce `acf` (lag 4)
  on held-out draws within the **uniform C3 tolerance: ±20% of the
  held-out real magnitude** (`amend_cards_c3.py` rule; floors apply) —
  The semi-Markov mirror fits dwell and one-step jumps; the lag-4 self-match ACF is determined by the chain's mixing over four steps (a convolution of the fitted dwell tail and jump matrix), not by any single fitted parameter, so it is a held-out test of whether run structure has the right longer-range decay.. Fail ⇒ mirror invalid ⇒ ABORT.
- **Measured-class filing:** if calibration measures this stream as something
  other than multi-class run/segment equality structure (e.g. one class
  dominates and the signature is binary-like self-excitation), the ledger cell
  is assigned by the MEASURED class, not this card's proposal.

## Amendment 2026-07-22 — Cycle-4 re-freeze (before any C4 calibration)

The C3 calibration ABORTED on gate-8 alone: the signal was C3's strongest
(self-match ACF(1) 0.479 ≫ N1 hi 0.204, κ = 0.609, split-half 0.461/0.495)
but the `semi_markov` mirror undershot held-out ACF(4) by 32% (0.201 vs
0.294) — the pooled self-match tail is a plateau a single global dwell+jump
process cannot hold, because **each document carries its own phase-propensity
profile** (the categorical analogue of the hedging plateau). The C3 review
recorded the fix as the C4 menu extension. Preregistered now, before any C4
run:

- **Record name:** `recipe-instruction-phase-runs-r2`. The C3 ABORT record
  stands untouched as the verdict under the C3 menu.
- **Mirror:** `hier_categorical` (the categorical `hier_ar1`): per-doc phase
  propensities (empirical list, deconvolved so the generator's within-doc
  stationary matches the observed doc marginal) + per-symbol empirical dwell +
  a global jump chain, mixed by a tilt weight α fit by MLE over jump events.
  Fitted quantities: dwell lists, jump chain, doc-marginal vectors, α.
- **Gate 8, HARDENED (≥2 non-fitted moments, ALL must pass — the C4 rule):**
  1. `acf[lag4]` — the C3 killer, kept: the doc-propensity list inserts the
     cross-doc heterogeneity *level* (as `hier_ar1`'s levels did,
     C3-review-approved precedent), but whether that mechanism carries the
     specific lag-4 self-match structure of HELD-OUT docs is a genuine
     out-of-fit check.
  2. `mi[lag2]` — pooled two-step MI: governed by the composition of
     within-doc dynamics with the cross-doc propensity spread on held-out
     docs, not by any single fitted parameter.
  Both under the uniform relative tolerance: ±20% of the held-out real
  magnitude, floors acf 0.01 / mi 0.003. Any fail ⇒ mirror invalid ⇒ ABORT.
- **Labels + labeler validation REUSED from the C3 record** (identical frozen

- **Coordinates + regime claim (checklist item 8, revamped rules):**
  spectral = mid (piecewise-constant phase state: DC-ish runs with AC
  boundaries); interaction order = **equality** (the primary latent is the
  equality-adjacency `[c_t = c_{t-1}]`, a comparison BETWEEN positions);
  stationarity = spread (instruction phases run through the document, not
