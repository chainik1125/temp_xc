## 0. Identity
- **Property:** List/enumeration sentences ('First,... Second,... Next,...') recur at a preferred cadence within how-to and listicle documents.
- **Ledger cell:** domain = `text-corpus` · temporal-class = `periodic`
- **Why it's not already covered:** periodic in text-corpus is empty; probes rhythmic list-item recurrence, a period-structured phenomenon distinct from stance drift.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Enumerated content produces regularly-spaced list-marker sentences interleaved with elaboration, yielding a preferred period in the enumeration indicator. A spectral peak in the item-marker series that vanishes under permutation would confirm periodicity.
- **What would make it ABORT:** No spectral peak — list markers appear aperiodically or clustered at doc start (position trend), with a flat periodogram indistinguishable from N3.
- **Composition risk:** medium + listicles have many markers, prose docs few (across-doc composition); the within-doc PERIOD is order structure N1 destroys.

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): Sentence begins or contains an explicit enumeration/ordinal step marker.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label one sentence from a web document. Output 1 if it is an ENUMERATION/STEP item — it opens or marks a numbered or ordinal step in a list or procedure. Output 0 otherwise. Examples: 'First, preheat the oven to 350 degrees.' -> 1. 'Step 3: add the flour.' -> 1. 'Next, we turn to the second consideration.' -> 1. 'The oven should be hot before you begin.' -> 0. Judge the single sentence; context helps confirm it belongs to an ongoing list.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Regex: /^(first(ly)?|second(ly)?|third(ly)?|next|then|finally|step \d+|\d+[\.\)]|lastly)\b/i -> 1.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 400 English web documents sampled from HuggingFaceFW/fineweb (sample-10BT, streamed, seed=0), filtered to 60-200 sentences per document, sentence-segmented with a pinned regex splitter. The unit of time is the sentence index within a document. Pinned at experiments/explorations/synthetic/expansion/data/fineweb_sample.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** periodogram of enumeration indicator; dominant period + prominence; ACF ringing at multiples of period
- **Expected signature:** Spectral peak at the item-spacing period with harmonic ACF. N1/N2/N3 give flat spectra; the ordered peak is the signal.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = enumeration base rate; oracle = inter-judge agreement. Floor: all-0 accuracy.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: Fires on ordinal-marker tokens; cannot encode spacing period.
- window families (TXC-pre/-post/Stacked/Spectral): Windows matched to item spacing peak; mismatched sizes degrade, exposing periodicity.

## 7. Mirror (Appendix B), to be fit only if the gate PASSES
- **Process:** `periodic_rate`. **Matched param(s):** the preferred enumeration period and marker rate.
  **Deliberately NOT matched:** the content of each list item
