## 0. Identity
- **Property:** Sentences that reintroduce a named entity (vs pronoun-only reference) recur with heavy-tailed gaps as referents are periodically re-anchored across long spans.
- **Ledger cell:** domain = `text-corpus` · temporal-class = `long-memory`
- **Why it's not already covered:** long-memory in text-corpus is empty; probes heavy-tailed renewal of full-noun re-mention (coreference re-anchoring) beyond short lags.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Discourse alternates between pronoun chains and re-introduction of the full entity name; re-anchoring happens sporadically with long gaps, giving a heavy-tailed renewal process. Unlike short-range clustering, gaps should have CV>1 and slow ACF decay, reflecting long-memory in reference management.
- **What would make it ABORT:** Re-anchor gaps are geometric (no heavy tail) OR full-name mention is uniformly random per sentence (no renewal structure) — CV~1 and fast ACF decay.
- **Composition risk:** medium + entity-heavy docs (bios) vs abstract docs differ (composition), but the GAP structure between re-anchors is within-doc order that N1 destroys.

## 2. Labeler
- **Signal:** per-sentence `binary` (n_values=2): Whether the sentence introduces/re-introduces a full named entity (proper noun) as its main subject rather than referring pronominally.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label one sentence from a web document. Output 1 if its main subject is a FULL NAMED ENTITY (a proper noun — person, place, organization, product — stated by name). Output 0 if the main subject is a PRONOUN or generic reference ('it', 'they', 'this', 'the company' without naming). Examples: 'Barack Obama signed the bill.' -> 1. 'Apple released a new phone.' -> 1. 'He signed it the next day.' -> 0. 'They released it last week.' -> 0. Use context to judge whether the sentence names the entity or refers back to one.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Regex: subject region contains a capitalized multi-token proper noun not at sentence start-only, AND sentence does not begin with pronoun set {he, she, it, they, this, that, these, those} -> 1.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 400 English web documents sampled from HuggingFaceFW/fineweb (sample-10BT, streamed, seed=0), filtered to 60-200 sentences per document, sentence-segmented with a pinned regex splitter. The unit of time is the sentence index within a document. Pinned at experiments/explorations/synthetic/expansion/data/fineweb_sample.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** inter re-anchor gap distribution (CV, tail index); ACF of indicator at lags 1-30; gap survival function slope
- **Expected signature:** Heavy-tailed gaps (CV>1), slow ACF decay beyond geometric N3. N1 destroys gap ordering; N2 keeps any positional trend but not the renewal tail.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = full-name base rate; oracle = inter-judge agreement. Floor: all-majority-class accuracy.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: Detects proper-noun/pronoun tokens; cannot represent long recurrence gaps.
- window families (TXC-pre/-post/Stacked/Spectral): Wide windows (>=16) needed to capture heavy-tailed re-anchoring; short windows fail, revealing long-memory.

## 7. Mirror (Appendix B), to be fit only if the gate PASSES
- **Process:** `semi_markov`. **Matched param(s):** the heavy-tailed re-anchor inter-event gap distribution.
  **Deliberately NOT matched:** which specific entities are named or their semantic role
