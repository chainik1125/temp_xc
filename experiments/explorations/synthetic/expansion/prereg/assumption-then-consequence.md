## 0. Identity
- **Property:** Consequence/derivation sentences depend on immediately-preceding assumption/case-introduction sentences in an order-sensitive way (assume-before-derive, not the reverse).
- **Ledger cell:** domain = `reasoning-trace` · temporal-class = `AC-order-sensitive`
- **Why it's not already covered:** AC-order-sensitive in reasoning-traces is empty; probes directed ordering (assumption must precede consequence) rather than a persisting state.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Reasoning has a directed grammar: assumptions/case-splits precede their consequences. The transition assumption→consequence should be far more frequent forward than backward, so a directed order statistic (forward vs time-reversed) diverges. This is genuinely AC: the marginal counts are identical under reversal, only the order differs.
- **What would make it ABORT:** Forward and time-reversed transition rates are equal (no directionality) — the label carries no order asymmetry, only marginal composition.
- **Composition risk:** low + both labels co-occur within nearly every proof-style trace; the signal is the directed adjacency, not per-doc composition.

## 2. Labeler
- **Signal:** per-sentence `ordinal` (n_values=3): Whether the sentence introduces an assumption/case (A) vs states a consequence/derivation from prior premises (C) vs neither.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label one sentence in a reasoning trace. 0 = neither. 1 = ASSUMPTION/CASE: introduces a supposition, case split, or 'let'/'suppose'/'assume'/'if' premise. 2 = CONSEQUENCE: derives a result that FOLLOWS from prior statements ('then', 'therefore', 'so it follows', 'this implies'). Examples: 'Suppose x is even.' -> 1. 'Consider the case where n=0.' -> 1. 'Then x squared is also even.' -> 2. 'It follows that the sum is divisible by 4.' -> 2. 'The problem gives three numbers.' -> 0. Judge this sentence; context tells you whether it opens a premise or discharges one.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Two lexicons: assume={suppose, assume, let, if, consider the case, in case}; consequence={then, therefore, so, thus, hence, it follows, this implies, which means}. Assign 1/2/0.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)

The unit of time is the sentence index within a trace. Pinned at results/c7_backtracking/stage_a/sentence_labels.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** forward P(consequence at t | assumption at t-1); same for time-reversed sequence; directed transition asymmetry index
- **Expected signature:** Forward assumption→consequence rate >> reversed rate. N1 (permutation) equalizes both directions; N3 gives product-of-marginals; the forward/reverse asymmetry survives only in true order.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = modal-class accuracy over {0,1,2}; oracle = inter-judge ordinal agreement. Floor: constant-modal predictor.

## 6. Predictions per architecture (blind — no arch is run this cycle)

- window families (TXC-pre/-post/Stacked/Spectral): Directional/causal window families (backward-looking) should beat symmetric ones, exposing order-sensitivity.
