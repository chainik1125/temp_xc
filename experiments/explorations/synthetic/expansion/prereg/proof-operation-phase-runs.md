## 0. Identity
- **Property:** Reasoning sentences enact one of several operation-types and cluster into same-operation runs (phases).
- **Ledger cell:** domain = `reasoning-trace` · temporal-class = `interaction/equality`
- **Why it's not already covered:** Unlike self-reference-echo (binary self-excitation) and operator-alternation (binary, negative-sign falsified), this is a 5-class per-sentence operation label whose equality-adjacency measures constant-label segments, not event clustering.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Chain-of-thought organizes into phases: a stretch of algebraic manipulation, then a stretch of case-enumeration, then a verification stretch. Because each phase is a coherent sub-task, consecutive sentences repeat the same operation-type far above the iid match rate, producing runs whose boundaries are true operation changepoints. Only position-comparing architectures expose the segment structure since the label itself is context-free.
- **What would make it ABORT:** self-match ACF(1) sits within ±band of the position-conditional iid null (N2) — i.e. operations are shuffled sentence-to-sentence with no runs.
- **Composition risk:** medium — algebraic sentences may dominate in arithmetic-heavy traces; the 75% cap and 10-category spread across math/logic prompts mitigate.

## 2. Labeler
- **Signal:** per-sentence `categorical` (n_values=5): which mathematical operation-type the single sentence performs (arithmetic/algebra, case-splitting, verification, restatement, or other) — judged from its own verbs/symbols.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label ONE sentence from a math reasoning trace by the operation it performs, using ONLY that sentence's own wording — never assume anything about neighbouring sentences. Output one integer 0-4. 1 = algebraic-manipulation: the sentence transforms/computes an expression or equation ('So 3x+2=11, thus x=3'; 'Multiplying both sides by 2 gives 4y=8'). 2 = case-enumeration: the sentence introduces or considers a specific case/possibility/branch ('Case 1: n is even'; 'Suppose instead that a>b'). 3 = verification-check: the sentence checks, tests, or confirms a result ('Let me verify: plugging x=3 back gives 11, correct'; 'This satisfies the constraint'). 4 = restatement-setup: the sentence restates the goal, defines notation, or sets up what to find ('We need to find the largest prime'; 'Let n denote the number of coins'). 0 = other: anything else (meta-comments, transitions, uncertainty). Judge only the sentence in front of you.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: lower-case the sentence. If it contains verify|check|confirm|plug.*back|satisfies|makes sense -> 3. Elif contains case |suppose |if we assume|either|branch|scenario -> 2. Elif contains we need|we want|let .* denote|define|find the|the goal -> 4. Elif contains =|plus|minus|times|divide|multiply|simplif|solve|substitut -> 1. Else -> 0. Apply in this priority order; return the first match.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 300 chain-of-thought reasoning traces from DeepSeek-R1-Distill-Llama-8B over math/logic prompts (10 categories x 30), already sentence-segmented: 25,528 sentences, mean 85 sentences/trace (median 91, max 169). The unit of time is the sentence index within a trace. Pinned at results/c7_backtracking/stage_a/sentence_labels.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** self-match ACF(1) (equality-adjacency); mean run-length; self-match ACF(4)
- **Expected signature:** ACF(1) well above all of N1/N2/N3; N2 (position-conditional iid) is the tightest comparison and real should exceed it by a clear margin from runs.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- chance = iid match rate ~sum p_c^2 (~0.25 for balanced 5-class); oracle = a labeler+Markov chain reproducing observed run-lengths.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: should read the current operation-type but not the run boundary; predicts equality-adjacency near chance.
- window families (TXC-pre/-post/Stacked/Spectral): windowed attention comparing c_t to c_{t-1} recovers the run structure and the elevated ACF(1).

## 7. Mirror (Appendix B), to be fit only if the gate PASSES
- **Process:** `semi_markov`. **Matched param(s):** empirical dwell-time distribution per operation-state + jump chain transition matrix.
  **Deliberately NOT matched:** self-match MI at lag 2 (cross-phase memory beyond immediate dwell)

## 8. Cycle-3 design gates (preregistered in this card)
- **Gate 7 (no-leakage):** categorical per-sentence CONTENT label, every class
  decidable from the sentence's own wording; labeling runs with **zero context
  sentences** (ctx=0). Classes: `0` = other/background; `1` = algebraic-manipulation; `2` = case-enumeration; `3` = verification-check; `4` = restatement-setup.
- **Primary statistic (fixed by the C3 recipe):** the equality-adjacency
  `[c_t = c_{t-1}]` — categorical self-match `acf1`, expected sign positive.
  The equality lives in the statistic, never in the label.
- **Gate 8 (non-fitted moment):** the `semi_markov` mirror must also
  reproduce `mi` (lag 2)
  on held-out draws within the **uniform C3 tolerance: ±20% of the
  held-out real magnitude** (`amend_cards_c3.py` rule; floors apply) —
  semi-Markov fits lag-1 dwell/jump directly; MI at lag 2 is governed by the composition of two transition steps and the phase-length tail, not by any single fitted parameter, so it is a genuine held-out check of the run structure.. Fail ⇒ mirror invalid ⇒ ABORT.
- **Measured-class filing:** if calibration measures this stream as something
  other than multi-class run/segment equality structure (e.g. one class
  dominates and the signature is binary-like self-excitation), the ledger cell
  is assigned by the MEASURED class, not this card's proposal.
