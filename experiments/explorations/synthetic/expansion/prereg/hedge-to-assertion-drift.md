## 0. Identity
- **Property:** Within web documents, expressed certainty drifts slowly — e.g. hedged framing early giving way to assertive claims later (or vice versa) as a persisting stance.
- **Ledger cell:** domain = `text-corpus` · temporal-class = `DC-slow-drift`
- **Why it's not already covered:** DC-slow-drift in text-corpus only has an ABORT (topic_switching); this probes a stance state whose marginal is homogeneous across docs but whose within-doc persistence is the signal — directly addressing the composition lesson.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Authorial certainty is a slowly-varying stance that persists across sentences and can drift within a document. Because most web docs mix hedges and assertions, the marginal is homogeneous, so persistence (high lag-1 ACF) must come from ordering, not composition. This is the clean DC-drift test the aborted topic property lacked.
- **What would make it ABORT:** Certainty ordinal has near-zero within-doc autocorrelation (iid) OR persistence is 82%+ per-doc composition again (a doc is uniformly hedged or uniformly assertive) — killed by N1, replaying the topic_switching failure.
- **Composition risk:** high + explicitly flagged: some docs may be uniformly one stance (composition); N1 is the exact discriminator and the calibration must confirm within-doc runs exceed permuted runs.

## 2. Labeler
- **Signal:** per-sentence `ordinal` (n_values=3): Degree of certainty/assertiveness in the sentence's claim.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label the CERTAINTY of one sentence from a web document. 0 = hedged (may, might, could, possibly, some argue, it seems). 1 = neutral/factual with no explicit stance. 2 = strongly assertive (certainly, definitely, undeniably, always, must, the fact is). Examples: 'This might improve outcomes for some users.' -> 0. 'The building was completed in 1930.' -> 1. 'This is undeniably the best approach.' -> 2. Judge from this sentence; use context only to resolve ambiguous stance.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Lexicon: hedge={may, might, could, possibly, perhaps, seems, some, arguably}; assert={certainly, definitely, undeniably, always, never, must, clearly, the fact}; sign->0/1/2.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)

The unit of time is the sentence index within a document. Pinned at experiments/explorations/synthetic/expansion/data/fineweb_sample.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** within-doc lag-1..lag-6 ordinal ACF; run-length distribution of same-certainty stretches; N1 permuted run-length vs observed
- **Expected signature:** Observed same-certainty runs longer than N1-permuted runs, and lag-1 ACF > N3. If ACF is entirely explained by per-doc mean (N1 matches observed), it ABORTS as composition.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = modal ordinal frequency; oracle = inter-judge agreement. Floor: modal-class predictor.

## 6. Predictions per architecture (blind — no arch is run this cycle)

- window families (TXC-pre/-post/Stacked/Spectral): Medium windows detect persistence; if only doc-global window helps, that signals composition not drift.
