## 0. Identity
- **Property:** Each sentence enacts a discourse-move (plan/execute/evaluate/conclude) and these persist in same-move runs.
- **Ledger cell:** domain = `reasoning-trace` · temporal-class = `interaction/equality`
- **Why it's not already covered:** Differs from both failed binary attempts by using a 4-class discourse-move content label; equality-adjacency of moves (not any refers-back or alternation relation) is the measured signature.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** A reasoning trace moves through discourse phases — planning the approach, executing steps, evaluating outcomes, concluding — and stays within a move for several sentences before transitioning. This yields same-move runs whose constant-label segments are the changepoint structure. The move is read from the sentence's own rhetorical framing, so equality lives only in the measured lag-1 match.
- **What would make it ABORT:** self-match ACF(1) does not exceed the within-doc permutation null N1 — moves are effectively interleaved sentence-by-sentence with no segments.
- **Composition risk:** medium — execute-step may crowd out others in long computations; discourse markers keep plan/evaluate/conclude above the 3% floor.

## 2. Labeler
- **Signal:** per-sentence `categorical` (n_values=5): which discourse-move the single sentence performs (plan, execute, evaluate, conclude, or other) from its own rhetorical markers.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
Label ONE sentence from a reasoning trace by its discourse-move, using ONLY that sentence's own wording; never reference neighbouring sentences. Output one integer 0-4. 1 = plan-approach: proposes a strategy or what to do next ('Let me try using induction'; 'First I will factor the polynomial'; 'The approach here is to count complements'). 2 = execute-step: carries out a concrete computation or deduction ('Adding these gives 12'; 'The derivative is 2x'; 'So the third term equals 8'). 3 = evaluate-outcome: assesses whether something worked or reflects on a result ('That does not seem right'; 'This gives a contradiction'; 'Good, the numbers match'). 4 = conclude-answer: states a final result or answer ('Therefore the answer is 42'; 'Hence x must be 5'; 'So the maximum is 100'). 0 = other. Judge only the sentence shown.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: lower-case. If contains therefore|hence|thus the answer|final answer|so the answer|the answer is -> 4. Elif contains let me try|i will|i'll|let's|the approach|first,|plan|strategy|instead try -> 1. Elif contains does not seem|doesn't|contradiction|wrong|good|correct|makes sense|hmm|wait -> 3. Elif contains =|gives|equals|so |adding|compute|derivative|therefore.*[0-9] -> 2. Else -> 0. First match in this order wins.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 300 chain-of-thought reasoning traces from DeepSeek-R1-Distill-Llama-8B over math/logic prompts (10 categories x 30), already sentence-segmented: 25,528 sentences, mean 85 sentences/trace (median 91, max 169). The unit of time is the sentence index within a trace. Pinned at results/c7_backtracking/stage_a/sentence_labels.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** self-match ACF(1) (equality-adjacency); self-match ACF(4); dwell-length CV
- **Expected signature:** real ACF(1) exceeds N1/N2/N3; the plan->execute->evaluate->conclude ordering also gives an asymmetric jump chain but the tested quantity is the equality-adjacency magnitude.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- chance = iid move-match rate; oracle = Markov chain over the four moves reproducing lag-1 match.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: labels the move per sentence but cannot see persistence; predicts chance-level adjacency.
- window families (TXC-pre/-post/Stacked/Spectral): lag-1 comparison recovers the segment runs and elevated ACF(1).

## 7. Mirror (Appendix B), to be fit only if the gate PASSES
- **Process:** `markov`. **Matched param(s):** 4x4 (+background) one-step transition matrix over discourse-moves.
  **Deliberately NOT matched:** run-length dispersion (dwell_cv) — the chain's geometric dwell is not fit to match observed CV

## 8. Cycle-3 design gates (preregistered in this card)
- **Gate 7 (no-leakage):** categorical per-sentence CONTENT label, every class
  decidable from the sentence's own wording; labeling runs with **zero context
  sentences** (ctx=0). Classes: `0` = other/background; `1` = plan-approach; `2` = execute-step; `3` = evaluate-outcome; `4` = conclude-answer.
- **Primary statistic (fixed by the C3 recipe):** the equality-adjacency
  `[c_t = c_{t-1}]` — categorical self-match `acf1`, expected sign positive.
  The equality lives in the statistic, never in the label.
- **Gate 8 (non-fitted moment):** the `markov` mirror must also
  reproduce `dwell_cv`
  on held-out draws within the **uniform C3 tolerance: ±20% of the
  held-out real magnitude** (`amend_cards_c3.py` rule; floors apply) —
  A plain Markov chain implies geometric dwell times with CV~1; the real dwell-length dispersion is a held-out consequence of the fitted self-transition probabilities only if dwells are truly geometric — deviation (over/under-dispersion from coherent phases) is not set by the fitted transition matrix and is a genuine test.. Fail ⇒ mirror invalid ⇒ ABORT.
