## 0. Identity
- **Property:** The reasoner's expressed confidence drifts slowly from hedged/uncertain early to committed/certain late within a trace.
- **Ledger cell:** domain = `reasoning-trace` · temporal-class = `DC-slow-drift`
- **Why it's not already covered:** DC-slow-drift in reasoning-traces is empty; probes a slowly-persisting confidence state distinct from discrete backtracking events.

## 1. Hypothesis (frozen)
- **Hypothesised temporal character + WHY:** Confidence should behave as a slowly-drifting latent that persists across many sentences and trends toward certainty as the solution converges. This is a smooth DC drift, not a clustered event, so ordinal confidence should show high lag-1 autocorrelation and a position trend that survives N1 but is flattened by N2.
- **What would make it ABORT:** Confidence ordinal is iid-like within trace (low autocorrelation) OR the trend is entirely position-driven and vanishes under N2 (pure trend, no persistent-state drift beyond trend).
- **Composition risk:** medium + some traces (easy problems) may be uniformly confident; but confidence marginal is broadly comparable and drift is a within-trace phenomenon N1 preserves.

## 2. Labeler
- **Signal:** per-sentence `ordinal` (n_values=3): Degree of expressed confidence/commitment in the sentence's claim.
- **Labeler + version:** Claude judge — bulk `claude-haiku-4-5-20251001`,
  adjudication `claude-sonnet-5`. Exact judge instruction (frozen):

```
You label the expressed CONFIDENCE of one sentence in a reasoning trace. 0 = hedged/uncertain (tentative, exploratory, questioning: 'maybe', 'I think', 'let me try', 'not sure'). 1 = neutral/procedural (a plain computation or statement with no stance). 2 = committed/certain (asserts a conclusion firmly: 'therefore', 'clearly', 'the answer is', 'this must be'). Examples: 'Maybe I should try substitution instead.' -> 0. 'Adding the two equations.' -> 1. 'So the answer is definitely 42.' -> 2. Judge from this sentence; use context only to disambiguate stance.
```

- **Validation plan:** held-out inter-judge agreement (Sonnet relabels a doc
  sample; raw agreement + Cohen's κ → symmetric-flip noise floor ε̂) + an
  independent heuristic cross-check: Lexicon score: +hedge for {maybe, perhaps, might, i think, not sure, let me try, possibly, seems}; +commit for {therefore, thus, clearly, definitely, must be, the answer is, hence, obviously}; map to 0/1/2 by sign.
  The stage-3 effect must survive label flips at ε̂ (the backtracking pattern).

## 3. Data (version-pinned)
- **Source:** 300 chain-of-thought reasoning traces from DeepSeek-R1-Distill-Llama-8B over math/logic prompts (10 categories x 30), already sentence-segmented: 25,528 sentences, mean 85 sentences/trace (median 91, max 169). The unit of time is the sentence index within a trace. Pinned at results/c7_backtracking/stage_a/sentence_labels.json.
- **Unit of time:** sentence index within a trace/document. Held-out split at
  the document level for signature stability + mirror validation.

## 4. Statistics + order-destroying null(s)
- **Ordered statistic(s):** lag-1..lag-8 autocorrelation of ordinal; position-binned mean confidence; variance of within-trace running mean
- **Expected signature:** Slow decaying ACF (persistence) plus a monotone position trend. N1 keeps the trend but destroys short-lag persistence; N2 keeps trend but destroys clustering of same-confidence runs; the persistent-run structure beats both.
- **Nulls:** N1 within-doc permutation; N2 position-conditional iid (trend-
  preserving); N3 iid global marginal. **Gate:** ordered must exceed the null
  beyond sampling noise AND the labeler noise floor ε̂, else ABORT.

## 5. Baselines
- Chance = predicting modal ordinal class; oracle = inter-judge ordinal agreement (Krippendorff). Floor: constant-prediction accuracy = modal class frequency.

## 6. Predictions per architecture (blind — no arch is run this cycle)
- per-token SAE: Captures hedge/commit lexicon per token; misses the slow drift because no cross-sentence state.
- window families (TXC-pre/-post/Stacked/Spectral): Medium windows (8-16) best capture persistence; very short windows lose the drift, confirming DC character.

## 7. Mirror (Appendix B), to be fit only if the gate PASSES
- **Process:** `ar1`. **Matched param(s):** the lag-1 autocorrelation (persistence) and drift trend of the ordinal.
  **Deliberately NOT matched:** the semantic coupling between confidence and actual solution correctness
